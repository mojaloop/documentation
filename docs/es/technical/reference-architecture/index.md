- title: En qué consiste
  details: En un sistema de software, una arquitectura de referencia es un conjunto de documentos de diseño de software que recogen la esencia del producto y sirven de guía para su evolución técnica. La arquitectura de referencia es la visión arquitectónica del diseño perfecto.
- title: Objetivos
  details: Identificar abstracciones, interfaces y oportunidades de estandarización; soluciones y patrones para problemas habituales; garantizar el cumplimiento de los principios de diseño técnico; ofrecer orientación sobre las arquitecturas de implementación; fomentar la innovación y la contribución, definiendo qué se puede hacer y cómo hacerlo
- title: Ventajas
  details: Bases para una hoja de ruta técnica; Orientación para la toma de decisiones sobre la elección de tecnologías y las estrategias de implementación; Armonización entre la visión técnica y la visión del producto
