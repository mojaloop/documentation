# Lista de interfaces comunes

La «Lista de interfaces comunes» incluye un listado de todas las interfaces comunes que se utilizan actualmente en la Arquitectura de Referencia «Mojaloop 2.0». Las interfaces comunes son utilizadas por varios contextos delimitados, de ahí su nombre.

Cada interfaz común que figura en la lista incluye la siguiente información: nombre del evento o Endpoint de la fuente o del editor, estilo de comunicación, contexto delimitado del editor o proveedor, una descripción de la función de la interfaz y una lista de los contextos delimitados en los que se utiliza.
