# Mojaloop Operaciones de transferencia a granel

Los procesos operativos que constituyen el núcleo del proceso operativo de transferencia;

- Proceso de preparación masiva a nivel de transferencia masiva
- Preparar el proceso en un único nivel de transferencia
- Fulfilment process for mass orders at the Mass Transfer level
- Llevar a cabo el proceso en un único nivel de transferencia
- Proceso de notificaciones a nivel de transferencia masiva
- Rechazar/Cancelar el proceso
- Procesamiento en bloque en un único nivel de transferencia para agrupar los bloques
