# Workstream Dispute Management
Este workstream busca desarrollar una solución de gestión de disputas que pueda integrarse con el Mojaloop Core y con los DFSP conectados, para satisfacer las necesidades de los operadores del Hub y de los DFSP participantes, en toda la gama de tipos de despliegue.

# Justificación de negocio
La naturaleza confiable de las transacciones de Mojaloop ha hecho necesario desarrollar una solución de código abierto hecha a medida para la gestión de disputas.

Las alternativas comerciales listas para usar suelen suponer que los sistemas de switch operan con un descubrimiento limitado y con poco o ningún acuerdo de términos, lo que da amplias oportunidades para la disputa y, en consecuencia, estas plataformas no se ajustan bien a un despliegue de Mojaloop.
