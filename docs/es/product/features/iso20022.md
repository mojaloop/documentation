# Práctica de mercado ISO 20022

La práctica de mercado ISO 20022 para Mojaloop proporciona un marco de mensajería estandarizado que permite a las instituciones financieras participar en el ecosistema de Mojaloop usando los estándares ISO 20022 reconocidos a nivel global. Esta especificación define cómo se implementan los mensajes ISO 20022 dentro del marco de Mojaloop como alternativa a la API FSPIOP.

## Documentos de práctica de mercado

* Documento de práctica de mercado
  * [ISO 20022 v1.0 (actual)](./Iso20022/v1.0/MarketPracticeDocument.md)

## Características clave

La implementación de ISO 20022 de Mojaloop proporciona:

- **Formato de mensaje JSON**: Adopta una variante JSON de los mensajes ISO 20022 para mejorar la compatibilidad con las API
- **Flujo de transacción en tres fases**: Mantiene las fases de descubrimiento, acuerdo y transferencia de Mojaloop
- **Soporte de conversión de divisas**: Gestiona las transacciones entre divisas con integración de proveedores de FX
- **Seguridad criptográfica**: Implementa ILP v4 para la firma segura de mensajes y el no repudio
- **Integración de API REST**: Integración fluida con las arquitecturas de API modernas basadas en REST

## Flexibilidad del esquema de pagos

Los documentos de práctica de mercado proporcionan:

- **Prácticas genéricas**: Directrices universales aplicables a todos los esquemas de pagos de Mojaloop
- **Marco extensible**: Permite personalizaciones y requisitos específicos del esquema de pagos
- **Soporte de cumplimiento**: Alineación con los requisitos regulatorios y los estándares del sector
- **Gestión de versiones**: Enfoque estructurado para gestionar la evolución de los estándares y los requisitos

Si tiene preguntas o necesita soporte, interactúe con la comunidad de Mojaloop a través de los canales oficiales.
