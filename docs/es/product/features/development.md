# Desarrollo continuo
Ningún software está terminado nunca, y Mojaloop no es la excepción. Siempre hay nuevas funcionalidades que considerar, nuevas API que implementar, nuevos portales que agregar y, por supuesto, siempre hay mantenimiento continuo, y la seguridad exige vigilancia constante.

La Hoja de ruta de Mojaloop aborda y prioriza estas necesidades, las sitúa en una línea de tiempo y las define como un conjunto de workstreams. Cada una de estas workstreams tiene un responsable del workstream, encargado de definir, gestionar y entregar el workstream a la Comunidad de Mojaloop. El responsable de el workstream cuenta con el apoyo de varios contribuyentes, que pueden ser ingenieros que ayudan a implementar una funcionalidad, o personas que pueden documentar la funcionalidad, o personas que ayudan a definir los requisitos.

## Líneas de trabajo candidatas
Además de los workstreams actualmente activas, tenemos varias workstreams candidatas que son "seguidoras rápidas" detrás de ellas; es decir, se han identificado como de alta prioridad, pero tal como están las cosas no hay capacidad suficiente dentro de la Comunidad para abordarlas. Estas son:

- Implementación de Liquidación V3.0
- Mejoras del Operator Portal: mejorar la UI y abordar las deficiencias percibidas en la funcionalidad
- Pagos a comercios: ampliar la solución actual, relativamente simple, para el registro de comercios y los pagos con código QR presentado por el comercio, con el fin de incluir algunos de los elementos más completos que necesitaría un esquema de pagos a comercios en producción.

Póngase en contacto con el Director de Producto si desea discutir alguna de estas workstreams candidatas, en particular cómo las convertimos en activas.
