# Introdução – Guia de Onboarding para o Operador do Hub

Este guia destina-se ao Operador de um Hub Mojaloop e fornece informação sobre o processo de onboarding dos DFSPs. Apresenta uma visão geral do percurso de onboarding seguido pelos DFSPs, funcionando como uma lista de verificação das atividades de onboarding. O objetivo é ajudar os colaboradores do Hub a compreender as etapas a concluir ao ligar os DFSPs aos vários ambientes do Hub.
