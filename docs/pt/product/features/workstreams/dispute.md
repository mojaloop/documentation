# Workstream de gestão de litígios
Este workstream tem por objetivo desenvolver uma solução de gestão de litígios que possa ser integrada com o core do Mojaloop e com os DFSPs (Digital Financial Services Providers) ligados, de modo a responder às necessidades dos operadores de hub e dos DFSPs participantes, em toda a gama de tipos de deployment.

# Justificação de negócio
A natureza fiável das transações Mojaloop fez com que surgisse a necessidade de desenvolver uma solução de código aberto (open source) feita à medida para a gestão de litígios. 

As alternativas prontas a usar assumem geralmente que os switches operam com uma descoberta limitada e com pouco ou nenhum acordo de termos, dando assim amplas oportunidades para litígios e, consequentemente, estas plataformas não se adequam bem a um deployment do Mojaloop.
