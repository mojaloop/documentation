# Prática de mercado ISO 20022

A prática de mercado ISO 20022 para o Mojaloop fornece um quadro de mensagens normalizado que permite às instituições financeiras participar no ecossistema Mojaloop utilizando as normas ISO 20022, reconhecidas a nível mundial. Esta especificação define como as mensagens ISO 20022 são implementadas no quadro do Mojaloop como alternativa à API FSPIOP.

## Documentos de prática de mercado

* Documento de prática de mercado
  * [ISO 20022 v1.0 (atual)](./Iso20022/v1.0/MarketPracticeDocument.md)

## Funcionalidades principais

A implementação ISO 20022 do Mojaloop fornece:

- **(Formato de mensagem JSON**: adota uma variante JSON das mensagens ISO 20022 para maior compatibilidade com APIs
- **Fluxo de transação em três fases**: mantém as fases de Descoberta, Acordo e Transferência do Mojaloop
- **Compatibilidade com conversão cambial**: trata transações entre moedas diferentes com integração de fornecedores de câmbio (FX)
- **Segurança criptográfica**: implementa o ILP v4 para a assinatura segura de mensagens e o não repúdio
- **Integração de API REST**: integração perfeita com arquiteturas modernas de API baseadas em REST

## Flexibilidade do scheme

Os documentos de prática de mercado fornecem:

- **Práticas genéricas**: orientações universais aplicáveis a todos os schemes Mojaloop (o scheme é o conjunto de regras do sistema de pagamentos)
- **Quadro extensível**: permite personalizações e requisitos específicos de cada scheme
- **Apoio à conformidade**: alinhamento com os requisitos regulamentares e as normas do setor
- **Gestão de versões**: abordagem estruturada para gerir a evolução das normas e dos requisitos
