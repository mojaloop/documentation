# Boas-vindas à Comunidade Mojaloop

## Como começar?

* Um bom primeiro ponto de partida é o [Guia do contribuidor](./contributing/contributors-guide.md), que fornece informação sobre como contribuir para o projeto.
* Para obter uma visão geral das tecnologias utilizadas no projeto, consulte a secção [Ferramentas e tecnologias](./tools/tools-and-technologies.md).
* Para ter uma ideia das funcionalidades que estamos a desenvolver, consulte o [Roadmap do produto](./mojaloop-roadmap.md).
* O [quadro do projeto](https://github.com/mojaloop/project#zenhub) mostra aquilo em que se está a trabalhar atualmente; é possível começar por uma [good first issue](https://github.com/mojaloop/project/issues?q=is%3Aopen+is%3Aissue+label%3A%22good+first+issue%22).

## Onde obter ajuda?

Junte-se às [discussões do Mojaloop no Slack](https://join.slack.com/t/mojaloop/shared_invite/zt-1qy6f3fs0-xYfqfIHJ6zFfNXb0XRpiHw) para contactar outros membros da comunidade.

## E se houver mais perguntas?
É possível consultar algumas das nossas perguntas frequentes na secção [FAQ (em inglês)](../../getting-started/faqs.md). Ou, melhor ainda, dirija-se à comunidade no [Slack](https://join.slack.com/t/mojaloop/shared_invite/zt-1qy6f3fs0-xYfqfIHJ6zFfNXb0XRpiHw).

## Como acompanhar as novidades do projeto?
Subscreva aderindo à [comunidade](https://community.mojaloop.io/), onde é possível receber notificações sobre os próximos [eventos](https://community.mojaloop.io/c/events/8) e [anúncios de produto](https://community.mojaloop.io/c/announcements/9). 

Também é possível aderir ao nosso canal de [anúncios no Slack](https://mojaloop.slack.com/messages/CG3MAJZ5J) para receber informação sobre a versão mais recente.
