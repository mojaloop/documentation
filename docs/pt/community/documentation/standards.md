# Documentação

### Visão geral

O Mojaloop estabeleceu várias normas para garantir que a documentação em todo o projeto é  consistente e se mantém atualizada.  

* Toda a documentação relevante para os contribuidores é mantida no repositório "documentation".
* O repositório "documentation" está sincronizado com o GitBook e todo o conteúdo é consumido num formato de leitura fácil em: [https://www.gitbook.com/mojaloop](https://www.gitbook.com/mojaloop)
* Toda a documentação deve incluir:
  * Visão geral: uma visão geral de negócio que apresente o valor ou a razão de ser da página de documentação
  * Detalhes: informação de síntese adequada para sustentar a documentação

### Guia de estilo da documentação

Toda a documentação nova deve estar conforme à documentação e aos estilos discutidos [aqui](style-guide.md).

### Idioma da documentação

Toda a documentação nova deve ser escrita em inglês, podendo depois ser traduzida para outros idiomas — está atualmente disponível também em francês. Está em curso o trabalho de tradução da documentação para espanhol e português.

A equipa de Localização desenvolveu diretrizes para tradutores, que se aplicam a todos os pares de idiomas. Estas [diretrizes de tradução estão disponíveis aqui, em inglês](../../../community/documentation/translationguidelines.md).

### Guia de estilo de código

#### NodeJS

Seguimos as [diretrizes de estilo Standard](https://github.com/feross/standard). Adicione `npm install standard` ao seu package.json.

#### Java
