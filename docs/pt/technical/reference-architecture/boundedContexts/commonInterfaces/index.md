# Lista de Interfaces Comuns

A Lista de Interfaces Comuns inclui uma lista de todas as interfaces comuns que se encontram atualmente em uso na Arquitetura de Referência Mojaloop 2.0. As Interfaces Comuns são utilizadas por vários Contextos Delimitados, daí o nome.

Cada Interface Comum aqui enumerada inclui as seguintes informações: nome do evento ou endpoint da fonte ou do editor, estilo de comunicação, Contexto Delimitado do editor/fornecedor, uma descrição da função da interface e uma lista de verificação dos Contextos Delimitados em que está a ser utilizada.
