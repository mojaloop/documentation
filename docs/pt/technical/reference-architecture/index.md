- title: O que é isto
  details: Num sistema de software, uma Arquitetura de Referência é um conjunto de documentos de conceção de software que captam a essência do produto e fornecem orientações para a sua evolução técnica. A Arquitetura de Referência constitui a visão arquitetónica da conceção ideal.
- title: Objetivos
  details: Identificar abstrações, interfaces e oportunidades de normalização; Soluções e padrões para problemas comuns; Assegurar o cumprimento dos princípios de conceção técnica; Fornecer orientações para as arquiteturas de implementação; Promover a inovação e a contribuição, definindo o que pode ser feito e de que forma
- title: Benefícios
  details: Base para uma roadmap técnica; Orientação para a tomada de decisões relativamente às escolhas tecnológicas e às estratégias de implementação; Alinhamento entre a visão técnica e a visão do produto
