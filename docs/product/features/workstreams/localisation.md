# Localisation Workstream
The Localisation workstream is responsible for making Mojaloop documentation accessible to non-English speaking adopters, starting with French. Following the initial French translation effort (Community, Technical, Adoption, Quickstart/Getting Started and Product pages, now peer-reviewed and merged), the workstream shifts focus from one-off translation to establishing a repeatable, maintainable localisation framework covering translation governance, contributor developer experience, page versioning, image/asset handling, and a documented process that additional languages can plug into.

# Business Justification
An increasing number of adopters and their engineering teams are non-English speakers, particularly across Francophone Africa. Consequently there is an urgent need for documentation that supports these adopters and their teams. This shouldn’t be limited to Product documentation, and the engineering teams are focussed on deployment and DFSP integration.

## Latest Update (Summary)
The Localisation workstream has completed translation of the planned documentation set and is now focused on long-term maintainability. Work is underway to automate the identification of documentation changes requiring translation and to establish sustainable processes for maintaining multilingual documentation. The team is also cataloguing untranslated diagrams and identifying editable source formats to support future localisation of graphical content.
